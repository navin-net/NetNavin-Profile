## About

**NetNavin Profile** is a static personal portfolio site designed to give visitors a quick, clear picture of who I am, what I do, and the projects I've worked on — similar to a traditional resume, but interactive and always up to date.

## ✨ Features

- Personal introduction / about section
- Skills overview
- Project showcase
- Contact information / links (GitHub, LinkedIn, email, etc.)
- Fully responsive design
